# PS4 UNLOCK FIX — versão inicial

Interface estática em português para PS4, com seletor de firmware, verificação documental e diagnóstico básico do navegador.

## Arquivos
- `index.html`
- `style.css`
- `app.js`

## Publicação
Ative GitHub Pages em **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Depois aguarde a publicação.

Endereço esperado: https://rickbjp26-prog.github.io/ps4-unlock-fix/

## Compatibilidade e limites
A lista inicial contém 13.02, 13.04, 13.50, 13.52 e 14.00 como versões citadas na matriz documental consultada. A interface não confirma que um exploit funcionará no console. O diagnóstico verifica somente elementos da página, HTTPS, seleção e conectividade.

## Exploit
Nenhum exploit ou payload é incluído ou executado nesta versão. Uma integração futura deve usar código-fonte auditado, compatibilidade comprovada por firmware, licenças e avisos preservados. Exploits podem falhar, travar ou reiniciar o console.

Projeto independente, sem afiliação com a Sony.
